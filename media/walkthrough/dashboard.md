# Your Copilot usage, locally

The dashboard shows, per machine:

- **Requests** — total and per-day, by category, language, and model.
- **Cost units** — the `copilotCredits` VS Code reports per request, as a running total, this-month total, daily budget bar, and burn-rate forecast.
- **Cost units by model** — which models actually consume your budget.
- **Model fit** — a heuristic flag for expensive models doing routine work.
- **Estimated time saved** — a rough, configurable estimate.

Run **Copilot Usage: Open Dashboard** any time.
